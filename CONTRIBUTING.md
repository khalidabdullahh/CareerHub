# 🤝 Contributing to CareerHub / FreeAICV.me

Thank you for your interest in contributing to **CareerHub** and the **FreeAICV.me** architectural ecosystem!

This repository contains the public specifications, technical architecture, and community documentation for FreeAICV.me, designed and exclusively owned by **Khalid Abdullah**.

---

## 🛠️ Contribution Guidelines

1. **Feature Proposals & Discussions:**
   - To propose a new template format, ATS rule, or tool workflow, please open a GitHub Issue first.
2. **Pull Requests:**
   - Fork the repository.
   - Create a clean feature branch: `git checkout -b feature/proposal-name`.
   - Submit a Pull Request against `main` detailing the enhancement.
